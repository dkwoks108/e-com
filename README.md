# Gabaya Legacy – Conscious Luxury E-Commerce Website

A modern, full-stack e-commerce website for **Gabaya Legacy** — a premium bio-vegan leather handbag brand handcrafted in India.

## 🌱 Brand

**Gabaya Legacy** is positioned as *"Conscious Luxury – Sustainable + Premium"*. The brand offers bio-vegan leather handbags at mid-range luxury pricing (~₹1,899–₹2,499), handcrafted in Jaipur, Rajasthan, India.

## 🛠 Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Language**: TypeScript

## 📄 Pages

| Page | Route | Description |
|------|-------|-------------|
| Home | `/` | Hero, featured products, brand values, testimonials, blog preview |
| Collections | `/collections` | All products with category filtering |
| Product Detail | `/collections/[id]` | Individual product page with related products |
| About | `/about` | Brand story, values, team, material explainer |
| Blog | `/blog` | Sustainable fashion articles |
| Blog Post | `/blog/[id]` | Individual article pages |
| Contact | `/contact` | Contact form with policies |

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📦 Build

```bash
npm run build
npm run start
```

## 🧹 Lint
